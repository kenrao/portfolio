# Technical Writing Portfolio

Documentation-engineering portfolio built with [Docusaurus](https://docusaurus.io/), showcasing docs-as-code workflows, an OpenAPI-driven API reference, interactive codelabs, and case studies on documentation systems and CI/CD publishing.

**Live site:** https://kenrao.github.io/portfolio/

## What this demonstrates

| Capability | Where to see it |
| --- | --- |
| Docs-as-code system (case study) | [Building a docs-as-code platform](https://kenrao.github.io/portfolio/docs/docs-as-code/overview) |
| CI/CD documentation pipeline | [CI/CD pipeline](https://kenrao.github.io/portfolio/docs/docs-as-code/cicd) |
| API documentation (OpenAPI) | [Users API reference](https://kenrao.github.io/portfolio/docs/api-doc-plugin/users-api) |
| Developer tutorials | [Sample codelab](https://kenrao.github.io/portfolio/docs/codelabs/setup-docusaurus) |
| Product onboarding | [Guided product tour](https://kenrao.github.io/portfolio/docs/onboarding/product-tour) |
| AI-assisted authoring | [AI-assisted workflow](https://kenrao.github.io/portfolio/docs/docs-as-code/ai-assisted) |

## Tech stack

- **Docusaurus 3** (React 19, TypeScript) static site generator
- **docusaurus-plugin-openapi-docs** for the interactive API reference
- **@docusaurus/theme-mermaid** for diagrams-as-code
- **driver.js** for the in-app onboarding tour
- **Vale** for automated style-guide checks
- **GitHub Pages** for hosting

> This repository hosts the published static build of the site. The source is maintained in a private repository.
