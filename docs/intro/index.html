Portfolio overview

I am a technical writer with 15+ years of experience creating product, developer, and API documentation. My background spans AI, DevOps, electronic design automation (EDA), semiconductors, cloud computing, and networking.

Profile summary​

I create clear, maintainable documentation for engineers and end users. I work closely with engineering, QA, product, and release teams to align documentation with active development cycles.

Across roles, I've owned installation guides, user manuals, release notes, API references, tutorials, online help, and internal developer portals. Recently, I've built docs-as-code systems that use Markdown or MDX authoring, Git-based review, automated publishing, and Vale style checks.

Core strengths​

  • Information architecture and content strategy for technical documentation
  • Docs-as-code workflows with Git as the source of truth
  • API reference and developer documentation
  • Structured authoring, content reuse, and documentation lifecycle management
  • CI/CD pipelines for documentation builds and publishing
  • Style-guide automation with Vale and custom linting
